# konsultan-lingker

Situs statis **Konsultan Lingker** — konsultansi lingkungan, laboratorium, dan pengujian lingkungan kerja. Dibangun dengan Astro 7 + Tailwind v4 menggunakan arsitektur **Frontmatter & Blocks** (data as content).

## Perintah

- `npm run dev` — server pengembangan
- `npm run build` — gerbang validasi lengkap (wajib lulus sebelum tugas selesai)
- `npm run preview` — pratinjau hasil build
- `npm run hooks:install` — pasang git hook pre-commit (stempel tanggal konten)

## Dokumen

- `docs/PRD-MIGRASI-WEBSITE.md` — PRD migrasi dan pengembangan situs.
- `AGENTS.md` — aturan wajib untuk agen/AI.

## Catatan identitas

Nama dagang **Konsultan Lingker**. Data badan hukum, kontak, dan domain masih menunggu konfirmasi (lihat PRD Bagian 1 & 12) dan sengaja belum diisi di `src/config/site.ts`.
